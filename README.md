🚀 Excited to Share My New Project – WordSmith: Anagram & Word Game! 🎮

I'm happy to introduce WordSmith, an interactive word puzzle game developed using HTML, CSS, and JavaScript.

✨ Key Features:

- Unscramble Mode
- Word Builder Mode
- Interactive scoring system
- Timer and streak challenges
- Hint and skip functionality
- Best score tracking
- Responsive design with dark mode support

💻 Technologies: HTML5 | CSS3 | JavaScript

🎯 Goal: To make vocabulary learning more interactive, enjoyable, and challenging through gaming.

This project helped me strengthen my frontend development skills and improve my understanding of JavaScript logic and DOM manipulation.
